# Todo App

A simple and interactive Todo App built with HTML, CSS, and JavaScript, integrated with Firebase Firestore for task persistence.

## Features

- Add tasks with a title, date, and time.
- Display tasks with a countdown for the remaining time.
- Mark tasks as completed or incomplete.
- Delete tasks with a confirmation modal.
- Persistent storage using Firebase Firestore.
- Responsive and user-friendly design.

## Technologies Used

- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Firebase Firestore
- **Icons**: Freepik
